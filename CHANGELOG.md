## Unreleased

Built over xlcalc 0.73.0. Breaking for a host: `@xlcalc/vue/local` needs xlcalc 0.73.0 or later (the peer range is `>=0.73.0`). A name the workbook does not define, or a function xlcalc does not know, is `#NAME?` only where it is computed, as in Excel (`IF(TRUE,1,Nope)` is 1).

- `./local` over a workbook whose calls outside it the host answers with promises (xlcalc 0.68.0's `externals.resolve`): a cell whose answer is still on its way when its call ends (past the call's `timeoutMs`) shows `#BUSY!` or `#GETTING_DATA`, and the source takes the answer as it arrives through the session's `settleConnections`, sending the cells it changed as a `changed` event. In Manual only the cells that asked (their own formula calls the function, shown waiting for it) show their answers, and every other cell waits for a calculation. Taking an answer past the calculator's deadline is tried once more with a minute's deadline; a failure is written to the console and the sheet reads its windows again. Closing the source ends the waits and asks the host nothing more ([local.md](docs/local.md#calls-outside-the-workbook)).

## 0.30.0 (2026-10-29)

What xlcalc 0.61.0 to 0.67.0 added for a sheet: sheet protection, the AutoFilter, calculation options, Paste Special in full, Go To Special, Create from Selection, the split window, tab color, gridlines and headings, rotated text, notes shown all the time and Workbook Statistics; the dialogs in Excel for Windows' words. Built over xlcalc 0.67.0. Breaking for a host: `@xlcalc/vue/local` needs xlcalc 0.67.0 or later (the peer range is `>=0.67.0`, it was `>=0.46.0`). A host that stored a workbook read with `keep: true` opens its file again before saving over it (`KeptRefusal` `layout`, below). Nothing else breaks for a host; a host that switches over every `SourceEvent` kind gets two kinds more (`calculation`, `sheets`).

- Excel's Tab Color: a sheet's `SheetInfo.tabColor` (`#RRGGBB`) fills its tab, or underlines it while it is active, and the source's new optional `tabColor(sheet, color)` gives the tab menu Tab Color with No Color and Excel's palette, a single undo step. `./local` reads, sets and writes it through xlcalc's `setLayout` (0.66.0); `memorySource` passes a sheet's `tabColor` through.

## 0.29.0 (2026-10-28)

A workbook on a server, edited by several viewers, and xlsx saved over the file it was opened from. Nothing breaks for a host; `keep` in `./local` needs xlcalc 0.57.0.

- A workbook on a server: `@xlcalc/vue/server`'s `serveSource(source, { access })` serves any source to every viewer of its workbook as a handler of standard requests and responses (`SourceServer.handle`, `close`), and `@xlcalc/vue/remote`'s `remoteSource(url, opts)` gives the browser's sheet a source with the methods the server allows the viewer. An edit by one viewer reaches the others at once through the source's events; the workbook has one undo history for all its viewers. The reads of one turn go as one request, answered call by call (Insert Function's signatures are one request). Neither entry needs the engine or Vue at runtime ([remote.md](docs/remote.md)).
- `./local` saves a workbook over the file it was opened from: `openXlsx(data, { keep: true })` reads through xlcalc's `openKept` (0.57.0 or later), and `saveXlsx(source, { over: data })` writes through `writeKept`, so the file's charts, pivot tables, pictures, theme and page setup stay as they were; a change the file cannot take rejects with xlcalc's `KeptRefusal`.
- `./local` keeps the display filter's rows for each filter (up to eight a sheet) until that filter is applied again, so viewers that share one source with different filters each keep theirs; a cleared filter no longer drops its rows.

Contents:

- `SheetView`: a virtualized grid over a `SheetSource`, with the workbook's styles, number formats, conditional formats, merged ranges, tables, hyperlinks and notes. It has:
  - editing with Excel's keys;
  - the formula bar as in Excel: always an input (a click places the caret at the click, a drag selects; on read-only sheets the text can be copied), a single line expanded by its arrow or Ctrl+Shift+U, references colored like their range borders on the grid, and Ctrl+click (Cmd+click) on a reference going to its range (with the key held, the reference under the pointer is underlined and the pointer becomes a hand; on a touch screen a long press on it goes to it), with Excel's Cancel and Enter buttons next to it and Insert Function (fx: search, Excel's categories, the ten most recently used, each function's syntax and description);
